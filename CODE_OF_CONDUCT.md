# Code of Conduct

## Our commitment
We aim to make participation in this project respectful, constructive, and harassment-free.

## Expected behavior
- Be respectful, patient, and considerate.
- Discuss ideas and technical decisions, not personal characteristics.
- Give and accept constructive feedback.
- Respect privacy; do not publish another person's personal information.

## Unacceptable behavior
Harassment, discrimination, threats, personal attacks, intimidation, doxxing, and sustained disruptive conduct are not acceptable.

## Scope
This policy applies in project repositories, issue and pull request discussions, and other spaces where someone represents this project.

## Reporting
Report conduct concerns privately to maintainers through the Kutra Corporation GitHub organization profile. Do not post sensitive details publicly.
Maintainers may edit or remove harmful content, reject contributions, or restrict participation where appropriate. No separate enforcement team or appeal process is currently published.
