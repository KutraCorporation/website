# Security Policy

## Supported versions
Security fixes are generally applied to the current default branch. No separate version support matrix is published.

## Reporting a vulnerability
Do not disclose suspected vulnerabilities in public issues, pull requests, discussions, or social media.

Use GitHub's **Report a vulnerability** flow on the repository Security tab:
https://github.com/KutraCorporation/website/security/advisories/new

This route is available only if private vulnerability reporting is enabled. If it is unavailable, contact maintainers through the Kutra Corporation GitHub organization profile and request a private reporting channel. Do not post exploit details publicly.

Include a concise description, potential impact, affected routes or versions, safe reproduction steps, and suggested mitigation where possible.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. No response-time or bounty commitment is currently offered.

## Safe harbor
Act in good faith. Avoid privacy violations, service disruption, data destruction, and accessing data that does not belong to you. Stop testing and report the issue if you encounter sensitive data.
