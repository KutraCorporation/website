# Support

## Where to ask
- **Reproducible bugs:** use the repository Bug report issue form.
- **Feature ideas:** use the repository Feature request issue form.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not report them publicly.
- **Usage questions:** check the README and `docs/` first.

Repository: https://github.com/KutraCorporation/website

A dedicated support portal, response-time commitment, and paid support offering have not been published. Do not include credentials, private keys, personal data, or production customer information in support requests.
